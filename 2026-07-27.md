## Developer Tools (3)

**Idea 6: READMEroast 🛠️ DEV TOOL**
Most devs have no idea if their README actually helps or confuses newcomers. This tool analyzes your GitHub README against top-performing repos, flags sections where readers typically bounce, and gives brutally honest, actionable feedback: "Your install section assumes knowledge of seven tools you never mention." Generates a "newcomer comprehension score" and a heatmap of where users get lost.

**Idea 7: DepSlim 🛠️ DEV TOOL**
Scans your package.json / requirements.txt / Cargo.toml and identifies dependency bloat — packages where you use 2% of the functionality but ship 100% of the bytes. Suggests lighter alternatives, shows "before and after" bundle size projections, and gamifies the cleanup with a "node_modules weight loss" tracker. The MyFitnessPal for your dependencies.

**Idea 8: GhostShip 🛠️ DEV TOOL**
Simulates a brand-new user navigating your SaaS product for the first time — recording every hesitation, misclick, and moment of confusion. Automated mystery shopping for SaaS onboarding.
